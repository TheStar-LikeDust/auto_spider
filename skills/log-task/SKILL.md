# Log Task

> 创建和追加更新任务日志。记录 agent 执行的每个小步骤。

## 与 Strategy 的区分

| 文档 | 文件名 | 内容 |
|------|--------|------|
| **Log** | `TASK_{name}_log.md` | 执行步骤记录（做了什么） |
| **Strategy** | `TASK_{name}_strategy.md` | 思考和决策记录（为什么这样做） |

**一致性要求**：
- 任务名称 `{name}` 必须相同
- 两个文档同步创建
- 递增式追加，不修改已有内容

## When to Use
- 用户分配新任务时创建日志
- 每个步骤执行前后追加记录
- 需要追溯执行历史

---

## 日志文件

位置: 项目根目录
```
TASK_{task_name}_log.md
```

示例: `TASK_电商产品数据_log.md`

## 追加步骤（每个操作）

每次执行操作前后，追加以下格式：

```markdown
## 步骤 {N}: {步骤标题}

- **时间**: {YYYY-MM-DD HH:MM}
- **计划**: {plan_xxx 或 无}
- **阶段**: 侦察 / Action / Parse / Extract / 验证
- **目的**: {这一步要做什么}

### 执行操作
{具体命令/修改的文件}

### 结果
- **状态**: 成功 / 失败
- **输出**: {关键输出信息}
- **文件**: {生成/修改的文件}

### 备注
{观察/问题/决策}

---

```

---

## 追加规则

**追加模式**: 只在文件末尾添加，不修改已有内容

**追加时机**:
| 事件 | 追加内容 |
|------|---------|
| 新任务 | 创建日志头部 |
| 创建 plan | 更新计划列表 |
| 执行步骤前 | 添加步骤条目（目的/预期） |
| 执行步骤后 | 填充结果/输出/备注 |
| 任务完成 | 更新头部状态 |

## 完整示例

```markdown
# 任务: 抓取电商产品数据

- **目标**: 从 example-shop.com 提取所有产品信息
- **创建时间**: 2024-01-15 10:30
- **状态**: 进行中

## 原始需求
用户说: "我需要爬取这个电商网站的所有产品，包括名称、价格、链接。"

## 计划列表
| 计划名称 | 用途 | 状态 |
|---------|------|------|
| plan_scout_shop | 侦察产品页面 | 完成 |
| plan_shop | 主爬虫 | 进行中 |

---

## 步骤 1: 侦察目标页面

- **时间**: 2024-01-15 10:32
- **计划**: plan_scout_shop
- **阶段**: 侦察
- **目的**: 了解页面结构，找到选择器

### 执行操作
1. 生成 scout plan: `python -m auto_spider generate scout --single-file`
2. 修改 URL 为目标页面
3. 运行: `python plan_scout.py`

### 结果
- **状态**: 成功
- **输出**: 找到 20 个产品项，Load More 按钮
- **文件**: plan_scout.py, output/scout_action_*/

### 备注
页面使用懒加载，需要滚动或点击加载更多。

## 步骤 2: 分析 page_info

- **时间**: 2024-01-15 10:40
- **计划**: 无
- **阶段**: 侦察
- **目的**: 确定交互元素选择器

### 执行操作
查看 output/scout_action_*/task1_action.json

### 结果
- **状态**: 成功
- **输出**: 
  - Load More: `.load-more-btn`
  - 产品链接: `a.product-link`

### 备注
无

---

## 步骤 3: 分析 clean_html

- **时间**: 2024-01-15 10:45
- **计划**: 无
- **阶段**: 侦察
- **目的**: 确定数据 XPath

### 执行操作
使用 clean_html 分析页面结构

### 结果
- **状态**: 成功
- **输出**:
  - 产品容器: `//div[@class='product-card']`
  - 标题: `//h2[@class='title']/text()`
  - 价格: `//span[@class='price']/text()`

### 备注
无

---
```
